# Changelog

## [v2.3] - 2026-02-08

### 🎓 Добавлено
- **Полностью переработан `hl learn`** — интерактивное обучение методологии пентеста
  - 7 разделов с пошаговым объяснением
  - Система XP за прохождение уроков
  - Интерактивный тест для проверки знаний
  - Живые примеры правильного/неправильного подхода

- **Новая лаборатория: Lab 2 — Network + Web Pentest**
  - Цель: `scanme.nmap.org` (легальная для обучения)
  - Фокус на связи сетевого сканирования и веб-тестирования
  - 4 этапа с подсказками: Разведка → Сканирование → Анализ → Уязвимости
  - Ключевые вопросы для мышления:
    - "Почему начать с network_info правильно?"
    - "Когда dir_buster лишний на этом этапе?"
    - "Как связать найденные порты с уязвимостями?"

### 🧠 Улучшено
- **Умный анализатор мышления** с новыми метриками:
  - Анализ времени между действиями (штраф за <30 сек, бонус за паузы)
  - Штраф за "шум" — лишние повторные запуски инструментов
  - Бонусы за стратегию и оптимальный путь
  - Конкретные рекомендации вместо общих фраз
  - Оценка эффективности (уникальные инструменты / общие действия)

- **CLI интерфейс**:
  - Интеграция Lab 2 в `hl lab start 2`
  - Исправлено логирование действий при использовании `hl scan`
  - Улучшены сообщения об ошибках и подсказки

### 🔧 Исправлено
- Двойной вывод инструментов (проблема в `load_tool_module`)
- Ошибки отступов в коде
- Проблемы с логированием действий в базу данных
- Очищена структура проекта от временных файлов

### 📚 Образовательный фокус
Проект теперь сфокусирован на обучении **мышлению пентестера**, а не просто на использовании инструментов:
- Правильная последовательность важнее количества действий
- Контекст и методология — ключ к успеху
- Каждый инструмент должен быть использован осмысленно

### 🚀 Для пользователей
- Начните с `hl learn` чтобы понять методологию
- Практикуйтесь на `hl lab start 2` с правильным подходом
- Используйте `hl analyze` для получения детальной обратной связи
- Стремитесь к оценке 80+ баллов за оптимальную стратегию
