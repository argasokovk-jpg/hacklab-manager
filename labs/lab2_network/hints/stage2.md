Этап 2: Сканирование портов

Цель этапа
Найти открытые порты.

Вопрос для мышления
Как связать найденные порты с уязвимостями?

Инструмент
hl port scanme.nmap.org

Что искать
Порт 80 - HTTP веб-сервер
Порт 443 - HTTPS защищенный веб
Порт 22 - SSH доступ
Другие порты

Логическая цепочка
Порт 80 найден -> есть веб-сервер -> нужен web_scanner
Порт 443 найден -> есть HTTPS -> нужен ssl_checker
Порт 22 найден -> есть SSH -> возможны SSH уязвимости

Ключевое предупреждение
НЕ запускай dir_buster сейчас!
Почему: не знаешь что за сервер
Не знаешь какие технологии
90% запросов бесполезны

Правильный порядок
port_check -> если есть порт 80/443 -> web_scanner -> потом dir_buster если нужно

Что дальше
80/443: переходи к Этапу 3
22: позже cve_lookup для SSH
Другие порты: определи сервис и проверь cve_lookup

Пример мышления
Нашел порт 443 открытым. Значит:
1. Есть HTTPS сервер
2. Нужно проверить SSL/TLS настройки
3. Нужно определить веб-технологии
4. Потом искать уязвимости
