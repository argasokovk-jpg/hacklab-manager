Этап 1: Разведка

Цель этапа
Собрать информацию перед сканированием.

Вопрос для мышления
Почему начать с network_info правильно?

Инструменты
hl network scanme.nmap.org
hl whois scanme.nmap.org

Объяснение
Начинать с network_info правильно потому что:
1. Узнаешь где физически находится сервер
2. Узнаешь кто провайдер
3. Понимаешь сетевой контекст цели

Если начать с port_check:
Сканируешь порты но не знаешь где цель
Нет контекста для интерпретации
Можешь нарушить закон сканируя не ту сеть

Что искать в network_info
IP адрес цели
Страна размещения
Интернет-провайдер
Информация о сети

Что искать в whois_checker
Кто владелец домена
Когда зарегистрирован
Контактная информация

Типичная ошибка
Неправильно: port_check -> network_info -> whois_checker
Правильно: network_info -> whois_checker -> port_check

Правильный подход
1. Узнай где цель
2. Узнай кому принадлежит
3. Теперь можно сканировать
